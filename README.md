# ChatGPT Markdown Downloader

ChatGPT Markdown Downloader is a lightweight browser extension built with [WXT](https://wxt.dev/) that lets you export your conversations from [chatgpt.com](https://chatgpt.com/) as clean Markdown files. Click the extension action button while viewing a chat and the entire thread is converted with Turndown and downloaded through the browser downloads API.

## Features
- One-click export of the active ChatGPT conversation to `chatgpt.md`
- Clean Markdown conversion via Turndown with fenced code blocks and ATX headings
- Works on `chatgpt.com` out of the box; adjust the match pattern to target other hosts
- Cross-browser builds for Chromium and Firefox using the WXT toolchain

## Prerequisites
- Node.js 18+ (required by WXT)
- [pnpm](https://pnpm.io/) 8+ (or run the scripts with your package manager of choice)

## Installation
```bash
pnpm install
```

## Developing locally
1. Start the development server for Chromium-based browsers:
   ```bash
   pnpm dev
   ```
2. Follow the URL that WXT prints in the terminal, or load the build output manually:
   - Open `chrome://extensions` (or `edge://extensions`).
   - Enable **Developer mode**.
   - Choose **Load unpacked** and select `.output/chrome-mv3/extension`.
3. For Firefox, use `pnpm dev:firefox` and load the extension from `.output/firefox-mv2/extension` via `about:debugging`.
4. The development server rebuilds automatically on file changes; refresh the extension to pick up updates.

## Building for release
- `pnpm build` – create production bundles in `dist/`
- `pnpm build:firefox` – production build targeting Firefox
- `pnpm zip` / `pnpm zip:firefox` – produce packaged ZIP archives suitable for store uploads

## Project structure
- `entrypoints/background.ts` – registers the browser action and triggers the download flow via `browser.scripting`
- `entrypoints/content.ts` – collects ChatGPT `<article>` nodes and converts them to Markdown with Turndown
- `utils/matches.ts` – central place to tweak the URL match pattern
- `public/icon/` – extension icons bundled into each build
- `dist/` – production build artifacts (generated)

## How it works
1. When you click the extension action button, the background script injects the content script into the active ChatGPT tab.
2. The content script walks every `<article>` element in the conversation, removes script/style tags, and feeds the result to Turndown for Markdown conversion.
3. The background script joins the sections, creates an in-memory data URL, and initiates a download named `chatgpt.md` using the browser downloads API.

## Linting and type checks
- `pnpm compile` – run TypeScript without emitting files
- `pnpm exec eslint .` – run ESLint (configured with auto-imports generated by WXT)

## Customization tips
- Want a different filename? Update the `filename` field inside `entrypoints/background.ts`.
- Need to target a different domain? Change `CONTENT_SCRIPT_MATCHES` in `utils/matches.ts`.
- Adjust Turndown behaviour (headings, code fences, etc.) in `entrypoints/content.ts`.

## Troubleshooting
- Make sure the extension only runs on HTTPS pages; non-HTTPS origins will be ignored by the match pattern.
- If downloads fail, check `chrome://downloads/` (or `about:downloads`) and the background page console for error messages printed by `browser.runtime.lastError`.
